# Задание 4. Перечень крупных задач по системам

Перечень для планирования RoadMap. Включает задачи MVP (ADR задания 3), передачи ставок в КЦ и партнёрский КЦ (ADR задания 4) и целевого решения на горизонте года.

Этапы:
- **MVP** — открытие депозита в интернет-банке, ADR задания 3 (6 месяцев);
- **КЦ** — передача ставок в кол-центр и партнёрский кол-центр, ADR задания 4 (входит в MVP, 6 месяцев);
- **Цель** — целевое решение: автоматическое открытие депозита без участия бэк-офиса (12 месяцев).

Сайт в перечень не входит.

## АБС (Oracle, PL/SQL, Delphi-клиент)

|**№**|**Задача**|**Этап**|
| :-: | :- | :-: |
|A1|Ведение базовых ставок в АБС вместо Excel (таблицы, процедуры, экран бэк-офиса кредитов)|MVP|
|A2|Заявки на депозит: очередь заявок, открытие депозита по заявке, СМС-уведомления клиенту|MVP|
|A3|Согласование персональной ставки, разделение доступа по ролям|MVP|
|A4|Outbox изменений ставок и статусов заявок|MVP|
|A5|Автоматическое открытие депозита без бэк-офиса по заявкам из ИБ и отделений|Цель|
|A6|Автоматическое назначение персональной ставки по правилам|Цель|
